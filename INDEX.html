⏰ How It Works

Every day at 6:00 AM:

  1. Zapier trigger fires automatically
  2. Gets list of Utah job board URLs from Supabase
  3. Extracts construction jobs using ScrapeGraphAI
  4. Writes new jobs to Supabase jobs table

No action needed after setup. It runs automatically forever.

❓ Troubleshooting

"Test failed in Zapier"

Check internet connection. Double-check Bearer token in Headers (no typos, full token copied).

"No jobs appearing in Supabase"

Wait until next morning (6 AM). Check Zapier Zap status in dashboard. View run logs.

"Authorization failed"

Make sure both headers are set exactly as shown in guide. Bearer token must be complete (long string).
